DevMax.

01 // PROJECT SUMMARY

A discussion-first coding forum

DevMax is an academic coding forum built around discussion-first collaboration. It gives developers a space to create threads, ask questions, share updates, comment, and vote through a community-style feed.

02 // PROJECT DEEP DIVE

Designed around community interaction

The project explores the core interactions that make developer communities useful: organized subthreads, visible voting, and focused conversations. Its Django backend and Tailwind CSS interface support a feed that feels structured while remaining open to ongoing discussion.

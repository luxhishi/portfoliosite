SafetyFirst VR.

01 // PROJECT SUMMARY

Practice safety through immersion

SafetyFirst VR is a virtual reality training environment where users practice responding to emergency scenarios such as fires and earthquakes. It turns safety knowledge into deliberate, repeatable practice so people can build confidence before an emergency happens.

02 // PROJECT DEEP DIVE

Turning procedures into reflex

In fire simulations, fires can break out at different points in the environment, requiring users to identify the fire classification and select the correct extinguisher. Earthquake scenarios test whether users can duck, cover, and hold on before safely exiting the area. Movement and decisions are scored throughout each simulation, with feedback at the end showing where the user can improve. By transforming emergency standards into measurable skills under pressure, SafetyFirst VR helps make the correct response more automatic when seconds matter.

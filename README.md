# Alex Morgan portfolio

A lightweight, responsive portfolio site that can be deployed directly to Vercel.

## Customize

1. Replace `Alex Morgan`, the intro copy, project names, and email in `index.html`.
2. Adjust the color tokens at the top of `styles.css` to match your identity.
3. Replace the abstract project panels with your own images if you have them.

## Deploy to Vercel

Import this folder as a new Vercel project. Since the site is static, use the default settings and leave the build command empty.
